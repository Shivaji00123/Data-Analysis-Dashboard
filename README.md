# Data-Analysis-Dashboard
I developed an interactive Power BI dashboard to analyze data, track key performance indicators (KPIs), identify trends, and generate meaningful business insights through dynamic visualizations. The project involved several stages, including data processing, data cleaning, and data visualization.

## Project Objective

Track total revenue, total orders, and units sold to understand the overall performance of 2025 to understand customers and grow more in 2026 and 2027.

## Data Collection

The dataset for this project was obtained from a publicly available online source. It was downloaded in Excel/CSV format and imported into SQL Server for data cleaning and preprocessing. After cleaning, the data was imported into Power BI to create interactive dashboards and identify important business insights.

### Tools Used
Microsoft Excel, SQL Server, Power BI.

## Questions (KPIs)
- Which electronic product generates the highest revenue?
- Which product has the highest quantity sold?
- Which products have the lowest sales?
- Which city generates the highest revenue?
- Which sales channel performs better: Online or Offline?
- Which month has the highest sales?
- Which month has the lowest sales?
- Who are the top 10 customers based on revenue?
- Which product category contributes the most revenue?
- What is the total revenue generated?
- What is the total sales quantity?

## Process
- Collected an electronic products sales dataset from a publicly available online source.
Downloaded the dataset in CSV/Excel format.
- Examine that data in Microsoft Excel
- Imported the raw dataset into SQL Server.
- Checked and handled NULL and duplicate values.
- Corrected incorrect data formats and inconsistent entries.
- Imported the cleaned dataset into Power BI.
- Create new columns in Power BI in new measures for profit, profit percentage, sales etc.
- Designed an interactive dashboard with a clean and professional layout.
- Organized charts and KPIs for easy understanding.
- Added relevant titles, labels, borders, and formatting.
- Enabled interactive filtering to explore business performance.
